# Stage info videos

Put the how-to videos here, with exactly these names. The 👁 button on each stage plays them:

| File | Stage |
|---|---|
| `1-download.mp4` | download the video and open it in the player |
| `2-trim.mp4` | trim |
| `3-actions.mp4` | record the actions |

To change the names or the texts, see `INFO` at the bottom of `app/js/help.js`.
