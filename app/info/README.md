# Stage info videos

The 👁 button on each stage plays these how-to videos:

| File | 👁 on stage | What it shows |
|---|---|---|
| `1-download.mp4` | download | download the next link, drop the video into the player |
| `2-trim.mp4` | trim | trim on the beat (count four 8s, Out on the 4) |
| `3-actions.mp4` | actions (part 1) | record the actions |
| `4-export.mp4` | actions (part 2) | export audio (to text) and the trimmed video |
| `5-upload-done.mp4` | actions (part 3) | upload both files, then Done + personal code |

They are 720p videos, about 1–3 MB each.
To change the names, the texts or which stage shows which video, see `INFO` in `app/js/help.js`.
